# Retail Inventory and Sales Management System

## Project Description

A relational database management system designed to manage
products, suppliers, purchases, sales, customers, returns,
stock movements, invoices and payments for a retail store.

## Technologies

- MariaDB / MySQL
- MySQL Workbench
- Python
- GitHub

## Database

Database Name: retail_inventory_db

The database contains 13 main tables covering:
- Products
- Categories
- Brands
- Suppliers
- Purchases
- Purchase Items
- Customers
- Sales
- Sale Items
- Returns
- Stock Movements
- Invoices
- Payments

## Implemented Features

- Relational database design
- 3NF normalization
- Primary and foreign key constraints
- Data integrity constraints
- Purchase processing
- Sales processing
- Return processing
- Stock management
- Invoice and payment management
- Business reports
- Stored procedures
- Database views

## Reports

- Low-stock products
- Stock valuation
- Supplier purchases
- Daily sales
- Monthly sales
- Returns
- Fast-moving products
- Product profit
